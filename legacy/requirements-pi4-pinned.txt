# RCB Control Runtime legacy Pi 4 pinned port baseline
#
# These are the EXACT versions running on the Pi 4 today (snapshot captured
# 2026-05-19). Use this file for the Pi 5 install so the new machine inherits
# a known-good runtime combination. After the port is verified, you can bump
# selected packages on both Pis as a separate sweep.
#
# Install order matters — pinocchio's metadata pulls newer numpy, so we
# install numpy FIRST and pinocchio's binary SECOND with the constraint
# already in place. See pi5_porting_plan.md §3.
#
# Spectral-BLDC and SourceRoboticsToolbox are pinned strictly to mirror Pi 4.
# Bump to PyPI's latest (Spectral-BLDC 1.19, SourceRoboticsToolbox 1.2) only
# after the Pi 5 port is fully verified and stable.
#
# roboticstoolbox-python is intentionally LEFT FLOATING — the latest PyPI
# release contains the C-extension memory-leak fixes that used to live as
# uncommitted local patches in ~/Documents/robotics-toolbox-python/. Letting
# pip pick the latest gives us those fixes baked in; pinning here would
# require knowing which version contains them.
