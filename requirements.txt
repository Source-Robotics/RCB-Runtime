# RCB Control Runtime Python dependencies
# Created: 2026-06-29 UTC; last reviewed: 2026-08-08 UTC.

# 2026-08-08 — audited every third-party import in the tree against this file. Added
#   `pinokin` (see below): it was imported by motion/cartesian_paths.py and installed in
#   .venv by hand, but never pinned — so a fresh `pip install -r requirements.txt` would
#   have produced a robot that could not plan Cartesian motion. That is the SAME failure
#   the 2026-07-12 note below describes for ruckig, two packages later. If you add an
#   import, add the pin in the same commit.
#   Verified all 24 existing pins match .venv exactly. NOTE the SYSTEM python (~/.local)
#   has different versions (numpy 2.4.6 vs the pinned 2.3.5) — .venv is what runs the
#   robot, so always check with `.venv/bin/python -m pip list`, never bare `python3`.
#
# 2026-07-12 — added ruckig. NOTE ruckig was already present in the SYSTEM python's
#   ~/.local but NOT in .venv, which is what actually runs the robot — hence the explicit
#   pin here. Since 2026-08-02 ruckig is no longer merely an opt-in EXEC profile: it is
#   the RTI mode POSITION RATE LIMITER, and without it RTI silently falls back to a legacy
#   cascade that does not converge. It is now load-bearing for safety, not a nicety.
#
# Pinned to the versions verified on the robot, in .venv.
# Install with:  pip install -r requirements.txt
#
# Target: Raspberry Pi 5, Python 3.11+ (RT kernel, Ubuntu).
# Versions are pinned (==) for reproducible installs. Bump deliberately.
